Combina todos tus overlays (Alertas, Chat, Metas, Enlaces Web) en un solo archivo para OBS. Acomódalos visualmente sin tener que mover múltiples fuentes en tu software de streaming.

Editor Maestro de Overlays

El editor está desactivado para ahorrar RAM

¿Cómo usar este nuevo sistema?

  1. La ventana de captura se abre sola al iniciar la app. Mantenla de fondo y captúrala en OBS usando Captura de Ventana (permite transparencia).
  2. Usa el Editor Visual de arriba para añadir tus overlays: Chat, Alertas, Música, Metas e URLs personalizadas.
  3. Arrastra los cuadros y ajústalos. Mantén presionada la tecla SHIFT al arrastrar las esquinas para hacer ZOOM / escalar su contenido.
  4. Una vez listo, dale a "Guardar Escena" dentro del editor.
